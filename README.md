# Taiwan Trainer

A Duolingo-style web app to learn essential Mandarin words before traveling to Taiwan. Built with [Lit](https://lit.dev/) web components and [Vite](https://vitejs.dev/).

## Features

- **Flashcard learning** — tap to flip cards, hear pronunciation via speech synthesis
- **Multiple-choice quiz** — test your knowledge with randomized questions
- **Progress tracking** — visual progress bar through lessons and quizzes
- **Audio pronunciation** — uses the Web Speech API with zh-TW voices
- **Mobile-friendly** — designed for phone-sized screens

## The Five Words

| Chinese | Pinyin | English |
|---------|--------|---------|
| 你好 | Nǐ hǎo | Hello |
| 謝謝 | Xiè xiè | Thank you |
| 對不起 | Duì bù qǐ | Sorry / Excuse me |
| 多少錢 | Duō shǎo qián | How much? |
| 好的 | Hǎo de | OK / Alright |

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Build for Production

```bash

```
